    MedScholar: semantic search for PubMed

    Problem
    Researchers search PubMed by guessing the exact keywords an author used.
    What we built
    Plain-English search that finds papers by meaning. We embedded 36M+ papers with MedCPT and compressed the 150 GB index to 4 GB with FAISS IVF-PQ.
    Result
    The whole engine runs on one AWS EC2 instance and answers in under 1.5 seconds.

    TechMedCPT · FAISS · FastAPI · Node.js/Express · React 18 + TypeScript · PostgreSQL · Redis · Docker · AWS EC2

    If you hire me

    My first 90 days at

    Small, observable and dependable in production. That's how I think agents should ship.

    Day 1 Day 1 Day 31 Day 61 Day 90

    1. Days 1–30

      Listen, then ship something small

      • Learn your stack, codebase and users before building any agent
      • Ship a small fix or internal tool by week two
      • Write an evaluation set for the AI workflows that matter to you

    2. Days 31–60

      Build one agent you can watch

      • Pick one painful manual workflow
      • Give the agent only the tools and permissions it needs, with guardrails
      • Trace every tool call, cost and failure

    3. Days 61–90

      Make it survive production

      • Keep a human in the loop where mistakes are expensive
      • Add deterministic fallbacks and measure the time it saves
      • Document it so anyone on the team can run it
